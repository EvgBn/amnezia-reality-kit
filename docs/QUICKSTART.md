# Quick start — IN server

← [Documentation](./README.md)

Deploy and day-to-day commands on one page. Traffic path: **client → AmneziaWG → this stack → REALITY OUT** (see [ARCHITECTURE](./ARCHITECTURE.md) if curious).

**Prerequisites:** Ubuntu 24.04+, Docker, free **UDP `AWG_PORT`** (default 58285). If host **:443** is a website, set `ENABLE_XRAY_INBOUND=0` in `.data/.env` before `make build` — [PORT-443](./PORT-443.md).

Deep reference: [DEPLOYMENT.md](./DEPLOYMENT.md), [OPERATIONS.md](./OPERATIONS.md), [TROUBLESHOOTING.md](./TROUBLESHOOTING.md).

---

## Path A — new server

Run in order (`sudo make deploy-host` **before** `make create-data`):

```bash
git clone git@github.com-amnezia-kit:EvgBn/amnezia-reality-kit.git ~/vpn-test
cd ~/vpn-test

sudo ./scripts/setup/install-docker.sh    # if Docker not installed
sudo make deploy-host                     # once per machine: kmod, firewall, boot
make check-host                           # fix FAIL before continuing

make create-data                          # .data/.env — fill OUT_* before clients work
make first-start                          # build → images → start
make awg-client-add NAME=phone
make check
```

Transfer `.data/clients_awg/phone.conf` to the device and use it in AmneziaWG. Run `make check` again on the server.

## Path B — migrate

```bash
cd ~/old-vpn-dir && make down
git clone … ~/vpn-test && cd ~/vpn-test
sudo make deploy-host                     # skip if already done
make create-data COPY_FROM=~/old-vpn-dir/.data/.env
make first-start
make awg-client-add NAME=phone   # if clients not copied
```

## Daily operations

```bash
cd <REPO_ROOT>
make ps          # stack status
make logs        # all containers
make check       # preflight phases 1–11 (fix FAIL lines)
```

Compose helper (when `make` wrappers are not enough):

```bash
dc() { docker compose -f .data/build/docker-compose.yml --env-file .data/.env "$@"; }
```

### Start / stop

| Action | Command | Notes |
|--------|---------|-------|
| Start (daily) | `make start` | Clears `.stack-stopped` + `up` + **host route** |
| Stop | `make down` | Containers down; survives reboot until `make start` |
| Bare up | `make up` | **Missing route** — prefer `make start` |
| Route only | `make route` | If stack up but AWG subnet unrouted |

### After changes

| Changed | Run |
|---------|-----|
| `.data/.env` or templates | `make build && make refresh-full` |
| `git pull` / image rebuild | **`make refresh-full`** |
| Ports / inbound / MTProxy / SNI | `make regression-443` — [VERIFY.md](./VERIFY.md) |
| AWG client add/remove | `make awg-client-add` / `make awg-client-remove` (auto refresh) |

**Do not** `docker restart` only `vpn-xray` or `vpn-amneziawg` after updates — breaks UDP voice ([VOICE.md](./VOICE.md)).

### Quick health

```bash
make ps                    # all vpn-* healthy
make route-status
make check                 # or make check 9 for stack only
```

### Backup (minimum)

Back up **`.data/.env`** and **`.data/clients_awg/`** (secrets + client exports).  
`.data/build/` is regenerated by `make build`. Snapshots: `.data/build-snapshots/pre-build-*`.

Full backup / restore / alerts: [OPERATIONS.md](./OPERATIONS.md).
